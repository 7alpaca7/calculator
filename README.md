# 复现功能
1. 标准计算器的样式 
2. 因窗口伸缩导致的历史记录模块的消失
3. 标准模式下的四则运算功能、平方根、平方、倒数、取余、清零使用（其他以前没用过，不熟悉功能，先不整）
4. 运算的历史记录及清除
5. 切换模式的侧边列表
